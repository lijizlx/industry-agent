## 1. 引言

### 1.1 编制目的

定义 IndustryAgent 前端展示层（React 18 + TypeScript + Vite + Ant Design 5）的工程结构、路由、页面、组件树、状态管理、请求层、实时推送与权限控制方案，指导前端开发。

### 1.2 技术基线

- 构建：Vite 5，Node 20；
- UI：Ant Design 5 + @ant-design/pro-components（ProTable/ProLayout）；
- 状态：Zustand（客户端状态）+ TanStack React Query v5（服务端状态）；
- 网络：axios 封装 + 原生 WebSocket 重连封装；
- 规范：ESLint + Prettier + husky + commitlint，严格 TS（`strict: true`）。

### 1.3 浏览器兼容

Chrome/Edge ≥ 100（厂内统一桌面环境），分辨率 ≥ 1366×768，大屏看板支持 1920×1080。

## 5. 状态管理方案

### 5.1 分工原则

| 状态类型 | 归属 | 工具 |
|---|---|---|
| 服务端状态（列表/详情/看板数据） | React Query | 缓存、失效、重试、轮询开箱即用 |
| 客户端会话状态（token/用户/角色） | Zustand useAuthStore | 持久化 localStorage（token 仅内存+sessionStorage，见 7.2） |
| UI 状态（主题/折叠/通知队列） | Zustand useAppStore / useNoticeStore | 跨组件轻量共享 |

### 5.2 React Query 约定

```typescript
// hooks/useQueryKeys.ts —— key 工厂，统一失效管理
export const qk = {
  anomalies: (f?: AnomalyFilter) => ['anomalies', f],
  anomaly: (id: string) => ['anomaly', id],
  rootcause: (taskId: string) => ['rootcause', taskId],
  approvals: (tab: 'pending' | 'done') => ['approvals', tab],
  dashboard: (range: '7d' | '30d' | '90d') => ['dashboard', range],
};
// 审批提交成功后：queryClient.invalidateQueries({ queryKey: qk.approvals('pending') })
// WS 推送到达后：invalidateQueries 对应实体 key（推送失效模式）
```

### 5.3 Zustand 示例

```typescript
export const useAuthStore = create<AuthState>()(persist(
  (set) => ({
    user: null, roles: [],
    setUser: (user, roles) => set({ user, roles }),
    hasRole: (r) => useAuthStore.getState().roles.includes(r),
    logout: () => { wsManager.close(); set({ user: null, roles: [] }); },
  }),
  { name: 'ia-auth', partialize: (s) => ({ roles: s.roles, user: s.user }) },
));
```

## 7. 请求层封装

### 7.1 axios 拦截器

```typescript
// src/api/request.ts
const request = axios.create({ baseURL: '/api/v1', timeout: 15_000 });

// 请求拦截：注入 Bearer token + trace 标头(X-Request-Id: crypto.randomUUID())
request.interceptors.request.use(cfg => {
  cfg.headers.Authorization = `Bearer ${useAuthStore.getState().accessToken}`;
  return cfg;
});

// 响应拦截：统一解包 { code, message, data }
request.interceptors.response.use(
  (res) => {
    if (res.data.code === 0 || res.data.code === '0') return res.data.data;
    message.error(res.data.message);          // 业务错误全局提示
    return Promise.reject(new BizError(res.data));
  },
  async (err) => {
    if (err.response?.status === 401) {       // 401 → 静默刷新
      return tokenRefreshQueue.enqueue(err.config);
    }
    if (err.response?.status === 403) { router.navigate('/403'); }
    if (err.response?.status === 429) { message.warning('请求过于频繁，请稍后再试'); }
    return Promise.reject(err);
  },
);
```

### 7.2 Token 无感刷新

- access_token 仅存内存；refresh_token 存 sessionStorage（关闭标签即失效）；
- 401 触发刷新：并发请求进入 `tokenRefreshQueue` 排队，单一刷新请求成功后统一重放；
- 刷新失败（refresh_token 过期）→ 跳转 Keycloak 重新登录；
- 登出调用 Keycloak end_session 端点 + 清理本地 store + 关闭 WS。

### 7.3 统一错误处理

| 层级 | 处理 |
|---|---|
| HTTP 4xx/5xx | 拦截器统一提示 + 跳转（401/403 专属逻辑） |
| 业务码 IA-1xxxx | BizError 抛出，页面可 catch 做局部兜底（如审批冲突 IA-12002 提示"该建议已被处理"） |
| 网络超时/断网 | React Query 自动重试 2 次（指数退避），失败显示重试占位 UI |

## 8. WebSocket 实时推送设计

```typescript
// hooks/useWebSocket.ts
// 连接: wss://host/ws?token=<JWT>（连接时校验，无效拒绝握手）
// 心跳: 客户端 30s ping，服务端 60s 未收到则断开
// 重连: 指数退避 1s/2s/4s/.../上限30s，重连成功后拉取离线增量
//      （断线区间通知通过 REST /notifications?since=lastEventId 补偿）
export function useWebSocket() {
  useEffect(() => {
    const ws = wsManager.connect();
    ws.on('anomaly.push', (evt) => {          // 新异常事件
      queryClient.invalidateQueries({ queryKey: ['anomalies'] });
      useNoticeStore.getState().push(evt);    // 铃铛红点 + toast
    });
    ws.on('task.status', (evt) => {           // 任务状态流转
      queryClient.invalidateQueries({ queryKey: ['agent-task', evt.taskId] });
      if (evt.status === 'WAIT_APPROVAL') notification.warning({ message: '新建议待审批' });
    });
    return () => ws.close();
  }, []);
}
```

事件负载结构（与 IA-SD-005 第 8 章契约一致）：

```json
{ "event": "anomaly.push", "eventId": "evt-20261015-0001",
  "data": { "anomalyId": "AN-20261015-0031", "equipmentCode": "ETCH-03",
            "param": "RF_POWER", "score": 0.87, "occurredAt": "2026-10-15T09:12:33+08:00" },
  "ts": 1760493153000 }
```

```tsx

<Access accessible={can('approval:approve')}>
```

## 项目统一口径速览

- **技术栈**：Egg.js 4.0（业务后端 + MCP Server）｜React 18 + TS + Vite + AntD 5｜Python FastAPI + LangGraph（智能体）｜PostgreSQL 16 + TimescaleDB + pgvector｜Neo4j 5｜MinIO｜Kafka｜Redis｜Prometheus + Grafana + OpenTelemetry｜Keycloak + OPA｜Docker Compose → K8s
- **智能体链路**：监控 Agent → 根因 Agent（Top-3 嫌疑）→ 建议 Agent → 审批 Agent（HITL 人工审批）→ 报告 Agent（8D 报告）
- **核心指标**：根因 Top-3 准确率 >80%｜MTTR 降低 >50%｜误报率 <10%｜人工接管率 <30%｜端到端延迟 <5min｜可用性 99.9%
- **硬约束**：数据不出域｜关键建议必须人工审批｜RBAC + 全链路审计
- **项目周期**：2026-10-19 ~ 2027-01-15（12 周 / 6 个迭代）

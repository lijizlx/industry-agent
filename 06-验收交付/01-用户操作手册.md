## 阅读说明

本手册面向**一线工程师**（工艺工程师、设备工程师、生产主管、质量工程师、系统管理员），不需要任何编程知识。手册中：

- "点击"指用鼠标左键单击一次；
- 【按钮名称】表示页面上的按钮文字，实际界面中以蓝色按钮样式显示；
- "路径"格式为：页面名称 > 菜单名称 > 按钮或标签名称；
- 各章节开头附界面布局的**文字描述与图位占位**（正式印刷版将替换为系统截图，占位格式为"〔图 X-X：××界面截图〕"）。

## 1. 系统简介与访问方式

### 1.1 系统是做什么的

IndustryAgent 是一个帮你快速回答以下问题的系统：

- "这条产线最近的良率怎么样？哪台设备异常最多？"
- "刚弹出来的 FDC 告警是什么情况？严不严重？"
- "这次良率下降，最可能的原因是哪三个？有什么证据？"
- "要不要调参？要不要停线？由谁拍板？"
- "8D 报告能不能别再让我从头写了？"

系统内置五个智能体（智能助手），按如下顺序自动工作：

```text
监控Agent（发现异常）→ 根因Agent（找Top-3嫌疑）→ 建议Agent（给出调参/停线建议）
→ 审批Agent（等你拍板）→ 报告Agent（自动写8D报告初稿）
```

**重要原则**：系统给出的所有建议都必须经过人工审批才会执行，你是最终决策人，系统只做"参谋"。

### 1.2 浏览器要求

| 项目 | 要求 |
|---|---|
| 推荐浏览器 | Chrome 110+ / Edge 110+ |
| 分辨率 | 建议 1920×1080 及以上 |
| 网络 | 需在公司内网（生产环境访问 https://ia.芯联.local；演示环境 http://localhost:5173） |
| 插件 | 无需安装任何插件 |

### 1.3 登录系统

**操作步骤：**

1. 打开浏览器，在地址栏输入 `https://ia.芯联.local`，回车；
2. 系统跳转到统一登录页（Keycloak 单点登录，页面顶部显示"芯联统一身份认证"字样）；
3. 输入公司域账号（工号）和密码；
4. 点击【登录】；
5. 登录成功后进入系统首页"良率看板"。

〔图 1-1：统一登录页截图 —— 页面中央为账号/密码输入框与蓝色"登录"按钮，左下角显示系统版本号〕

**首次登录提示**：首次登录后系统会要求你确认手机号/邮箱（用于告警通知），按提示填写即可。

### 1.4 登出系统

**操作步骤：**

1. 点击页面右上角你的姓名（或头像圆圈）；
2. 在下拉菜单中点击【退出登录】；
3. 系统返回登录页。

> 提示：共用电脑的同事请务必登出。系统也会在 30 分钟无操作后自动登出。

### 1.5 忘记密码

1. 在登录页点击【忘记密码？】；
2. 输入工号，点击【下一步】；
3. 按页面提示通过公司统一身份平台重置（密码由公司 IT 统一管理，本系统不单独设密码）；
4. 重置后返回本系统登录页重新登录。

如果账号被锁定（连续输错 3 次密码），请拨打 IT 服务台电话解锁。

## 2. 首页良率看板操作

### 2.1 看板总览

登录后首先看到的就是良率看板。界面从上到下分为四个区域：

〔图 2-1：良率看板首页截图 —— 顶部为标题栏与时间范围选择器，其下左右分为两个图表区与一个统计卡片区，底部为异常设备排名〕

| 区域 | 名称 | 位置 | 作用 |
|---|---|---|---|
| A | 顶部标题栏 | 页面最上方 | 系统名称、时间范围切换、刷新按钮 |
| B | 良率趋势图 | 左上大图 | 展示选定时间范围内的良率变化曲线 |
| C | OEE 趋势图 | 右上大图 | 展示设备综合效率变化曲线 |
| D | 异常统计卡片 | 中部一行 4 张卡片 | 今日告警数、待处理数、误报数、根因分析进行中数量 |
| E | Top 异常设备排名 | 底部横向条形图 | 异常次数最多的前 10 台设备排名 |

### 2.2 各卡片与图表的含义

#### 良率趋势图（区域 B）

- **横轴**：时间；**纵轴**：良率百分比（92%~98% 区间放大显示）；
- **蓝色实线**：实际批次良率；
- **绿色虚线**：目标良率（95%）；
- **红色圆点**：良率跌破阈值的批次，点击红点可查看该批次详情；
- **灰色阴影**：上下 3σ 控制限范围，阴影外的点属于异常波动。

〔图 2-2：良率趋势图放大截图，标注蓝线/绿虚线/红点/灰阴影各要素位置〕

#### OEE 趋势图（区域 C）

- OEE = 时间开动率 × 性能开动率 × 合格品率，是衡量设备"干得怎么样"的综合指标；
- 可按"产线"或"设备组"切换：点击图例上的【产线】/【设备组】标签页切换；
- 三条彩色实线分别对应 3 条产线（FAB-A1 / FAB-A2 / FAB-A3）。

#### 异常统计卡片（区域 D）

| 卡片 | 数字含义 | 点击后行为 |
|---|---|---|
| 今日告警 | 今天 0 点至今 FDC 告警总条数 | 跳转到异常事件列表（今日） |
| 待处理 | 状态为"待处理"的告警数 | 跳转到异常事件列表（待处理） |
| 误报 | 被人工标记为误报的告警数 | 跳转到异常事件列表（误报） |
| 根因分析中 | 正在由根因 Agent 分析的事件数 | 跳转到根因分析页（分析中） |

> 卡片右上角的小箭头（↑红/↓绿）表示与昨天同期的对比，红色上升代表告警变多，需关注。

#### Top 异常设备排名（区域 E）

- 横向条形图，条越长代表该设备在选定时间范围内告警次数越多；
- 点击任一设备条，跳转到该设备的异常事件列表，实现"钻取"。

### 2.3 切换时间范围

**操作步骤：**

1. 在顶部标题栏找到时间范围选择器（默认显示"近 24 小时"）；
2. 点击下拉箭头，可选：近 24 小时 / 近 7 天 / 近 30 天 / 自定义；
3. 选择"自定义"时，在弹出的日历框中点选起止日期，点击【确定】；
4. 看板所有图表与卡片在 3 秒内自动刷新。

> 小技巧：图表右上角的【刷新】按钮可手动刷新数据；图表左侧的下载图标可把当前图表导出为 PNG 图片，方便贴进周报。

### 2.4 钻取操作示例

**示例：想查良率趋势上那个红点批次。**

1. 点击良率趋势图中的红色圆点；
2. 弹出气泡框，显示批次号、良率值、落差、时间；
3. 点击气泡框中的【查看详情】；
4. 页面跳转到该批次详情，可继续点击【发起根因分析】或【查看关联告警】。

## 3. 异常事件监控

### 3.1 进入方式

左侧导航栏点击【异常事件】，默认进入告警列表页。

### 3.2 告警列表界面

〔图 3-1：告警列表页截图 —— 顶部为一行筛选器（设备/级别/状态/时间），其下为表格，右上角有导出按钮〕

**表格字段说明：**

| 字段 | 含义 |
|---|---|
| 告警编号 | 系统自动生成，形如 EVT-20261015-0001 |
| 时间 | 告警触发时间 |
| 设备 | 设备编号与名称，如 ETCH-03（刻蚀机 3 号） |
| 触发规则 | FDC 规则名称，如"腔压超限" |
| 级别 | 严重（红）/ 警告（橙）/ 提示（蓝） |
| 状态 | 见 §3.5 |
| 关联批次 | 受影响的晶圆批次号，可点击 |
| 操作 | 【详情】【标记误报】按钮 |

### 3.3 筛选与排序

**操作步骤：**

1. 使用表格上方筛选器组合筛选：
   - 设备下拉框：选择一台或多台设备；
   - 级别下拉框：严重 / 警告 / 提示；
   - 状态下拉框：待处理 / 处理中 / 已关闭 / 误报；
   - 时间选择器：默认近 24 小时；
2. 点击【查询】，表格刷新；
3. 点击任意列头（如"时间"）可按该列升序/降序排序，列头出现小三角箭头表示当前排序方向；
4. 点击【重置】清空全部筛选条件。

**导出**：点击右上角【导出 Excel】按钮，导出当前筛选结果的 Excel 文件。

### 3.4 查看事件详情

**操作步骤：**

1. 在列表中找到目标告警，点击该行【详情】；
2. 进入事件详情页，页面自上而下包含四个信息块：

〔图 3-2：事件详情页截图 —— 依次为基本信息区、参数快照区、处置时间线区、操作按钮区〕

| 信息块 | 内容 |
|---|---|
| 基本信息 | 告警编号、设备、触发规则、级别、触发时参数值与阈值、关联批次 |
| 参数快照 | 触发前后 30 分钟的关键参数曲线（黄线为实际值，红色水平线为阈值） |
| 处置时间线 | 每一步动作的"人/智能体 + 时间 + 动作"记录，例如"根因Agent 10:32 输出 Top-3 嫌疑" |
| 操作按钮 | 【发起根因分析】【标记误报】【关闭事件】 |

3. 如需人工触发根因分析（例如事件未自动触发），点击【发起根因分析】并填写原因。

### 3.5 实时推送说明

- 保持告警列表页或系统任意页面打开时，新告警会通过 WebSocket **实时推送**，无需手动刷新；
- 推送形式：
  1. 页面右上角弹出通知条（显示设备、级别、规则），5 秒后自动收起；
  2. 告警列表顶部新插入一行，背景短暂高亮为浅黄色；
  3. "严重"级别告警同时发送企业微信通知（需在个人设置中绑定，见 §8.1）；
- 点击通知条可直达该事件详情页；
- 若连续 1 分钟未收到推送且怀疑异常，点击页面右上角的连接状态图标（绿色圆点=正常，红色=断开），断开时点击【重新连接】。

### 3.6 事件状态说明

| 状态 | 图标颜色 | 含义 | 谁能改变 |
|---|---|---|---|
| 待处理 | 红色 | 新告警，尚未响应 | 系统自动生成 |
| 处理中 | 橙色 | 已有人认领或根因分析进行中 | 设备/工艺工程师 |
| 已关闭 | 绿色 | 处置完成并确认恢复 | 处置人本人或生产主管 |
| 误报 | 灰色 | 人工标记为非真实异常 | 工程师标记，质量工程师复核 |

## 4. 根因分析操作

### 4.1 什么时候会看到根因分析

- "严重"级别告警触发后，系统**自动**发起根因分析；
- 其他级别告警可在事件详情页点击【发起根因分析】人工触发；
- 看板"根因分析中"卡片显示正在分析的事件数，点击可进入列表。

### 4.2 查看 Top-3 嫌疑

**操作步骤：**

1. 左侧导航点击【根因分析】，或在事件详情页点击"查看根因分析"链接；
2. 根因分析页顶部为事件摘要（事件、时间、异常参数）；
3. 下方为 **Top-3 嫌疑卡片**，按可能性从高到低排列：

〔图 4-1：Top-3 嫌疑卡片截图 —— 三张并排卡片，每张含根因名称、置信度进度条、类别标签、证据数量角标〕

| 卡片元素 | 含义 |
|---|---|
| 嫌疑名称 | 例如"ETCH-03 腔体压力传感器漂移" |
| 置信度 | 0%~100% 的进度条与数字，含义见 §4.4 |
| 类别标签 | 设备漂移 / 腔体污染 / Recipe 错配 / 传感器故障 / 来料异常 / 环境波动 |
| 证据角标 | 该嫌疑下的证据条数（图谱 / 曲线 / 案例 / 因果） |
| 【确认】【排除】按钮 | 人工确认或排除该嫌疑（确认后触发建议 Agent） |

4. 点击任一嫌疑卡片，进入该嫌疑的**证据链详情**（§4.3）；
5. 若三个嫌疑都不对，点击页面底部【都不对，反馈新根因】，填写真实根因——你的反馈会让系统越用越准。

### 4.3 证据链逐项查看

嫌疑详情页顶部有四个标签页：**图谱关系 / 参数曲线对比 / 相似案例 / 因果结论**。

#### 标签页 1：图谱关系（知识图谱）

〔图 4-2：知识图谱视图截图 —— 中央为嫌疑节点，周围放射状连接设备、参数、工艺步骤、历史缺陷节点，节点大小不同，连线有粗细〕

- **圆点（节点）**：一个"事物"，如设备（方形蓝色）、参数（圆形绿色）、工艺步骤（六边形紫色）、历史缺陷（菱形橙色）；
- **连线**：两个事物的关联，线越粗表示历史上共同出现的频次越高；
- **操作**：
  1. 鼠标悬停节点：浮窗显示该节点的说明与统计；
  2. 鼠标滚轮：缩放图谱；
  3. 按住拖动：移动整个图谱；
  4. 双击节点：展开该节点的下级关联；
  5. 图谱右下角【图例】按钮：查看节点颜色含义；
  6. 【全屏】按钮：放大到整屏查看。

#### 标签页 2：参数曲线对比（时序）

〔图 4-3：参数曲线对比截图 —— 双曲线叠加图，绿色为正常基线带，蓝色为当前实测曲线，红色竖线标注告警时刻〕

- 上拉菜单可切换不同参数（腔压、温度、气体流量等）；
- 绿色区域：该参数过去 30 天的正常波动带（基线）；
- 蓝色实线：本次事件的实际曲线；
- 可以直观看到"哪一刻开始跑偏、跑偏了多少"；
- 底部滑块可缩放时间窗口；右上角可叠加"同型设备同期曲线"做横向对比。

#### 标签页 3：相似历史案例

- 系统检索出最相似的 5 条历史案例，按相似度（百分比）排序；
- 每条案例显示：发生时间、设备、当时的根因、当时的处置措施、恢复耗时、当时的 8D 报告链接；
- 点击案例行可展开完整描述；
- 用途：**看看前人怎么处理的，快速形成处置思路**。

#### 标签页 4：因果结论

- 以结论卡 + 因果方向图的形式展示智能体的因果推断：
  - 结论文本示例："腔压传感器读数漂移与批次 B-2026-1024 良率下降存在显著因果效应（效应量 -2.1%，置信度 87%）"；
  - 因果方向图：箭头从"原因节点"指向"结果节点"，箭头粗细代表效应强度；
- 页面底部附"推断依据"折叠框，列出使用了哪些数据与规则，保证结论可追溯。

### 4.4 置信度的含义

| 置信度区间 | 含义 | 建议做法 |
|---|---|---|
| ≥ 85% | 证据充分，多路证据一致 | 优先核对，大概率可确认 |
| 60% ~ 85% | 有较强证据但存在其他可能 | 结合曲线对比与现场检查判断 |
| < 60% | 证据不足，仅供参考 | 务必人工排查，勿直接照做 |

> 置信度 ≠ 正确率。它表示"系统对这个结论有多大把握"。即使置信度很高，最终决策仍然是你的责任。

### 4.5 确认/排除嫌疑

1. 在嫌疑卡片上点击【确认】或【排除】；
2. 系统弹窗要求填写**确认/排除依据**（至少 10 个字）；
3. 提交后：
   - 确认 → 自动触发建议 Agent 生成处置建议，并进入审批工作台（§5）；
   - 排除 → 该嫌疑卡片置灰，系统重新计算其余嫌疑排序；
4. 全部操作记入审计日志（人、时间、动作、理由）。

### 4.6 导出分析报告

1. 在根因分析页右上角点击【导出分析报告】；
2. 选择格式：PDF（推荐）或 Markdown；
3. 报告包含：事件摘要、Top-3 嫌疑与置信度、全部证据（图谱截图、曲线图、案例、因果结论）、分析耗时、分析版本号；
4. 点击【导出】，浏览器下载文件，默认文件名 `RCA_事件编号_日期.pdf`。

## 5. 建议审批工作台

### 5.1 谁会用到这个模块

- **审批人**：工艺工程师（审批调参建议）、生产主管（审批停线建议）；
- **提单人**：任何工程师都可以查看建议详情并了解进度；
- 建议由建议 Agent 自动生成，**未审批的建议不会自动执行**。

### 5.2 待办列表

**操作步骤：**

1. 左侧导航点击【审批工作台】；
2. 默认显示"待我审批"标签页，列出等待你审批的建议：

〔图 5-1：审批工作台截图 —— 顶部为三个标签页（待我审批/我已审批/全部），其下为建议卡片列表，每张卡片右上角有倒计时提示〕

| 卡片元素 | 含义 |
|---|---|
| 建议类型 | 调参建议（蓝）/ 停线建议（红） |
| 建议内容摘要 | 例如"将 ETCH-03 RF 功率从 1500W 下调至 1450W" |
| 关联根因 | 显示来源嫌疑与置信度 |
| 风险等级 | 低 / 中 / 高 |
| 影响范围 | 受影响设备、批次、预计产能影响 |
| 倒计时 | 距离"超时自动升级"的剩余时间（停线建议 30 分钟未审自动升级至生产主管） |

3. 点击卡片进入**建议详情**，可展开查看：建议参数对照表、根因证据链接、预计收益（如"预计良率恢复 +1.8%"）、历史相似建议的执行效果。

### 5.3 审批通过

**操作步骤：**

1. 打开建议详情，逐一核对：根因证据是否可信、参数变更是否合理、影响范围是否可接受；
2. 点击右上角绿色【通过】；
3. 在弹窗中填写**审批理由**（必填，例如"同意，按曲线漂移证据执行，观察 2 个批次"）；
4. 点击【提交】；
5. 页面显示"审批完成"，该建议进入"已批准"状态并流转至执行/记录环节；停线建议通过后会同时通知产线班组。

### 5.4 审批驳回

**操作步骤：**

1. 在建议详情点击红色【驳回】；
2. 选择驳回原因（下拉）：根因不成立 / 建议过于激进 / 影响范围不可接受 / 数据存疑 / 其他；
3. 填写驳回说明（必填），如选择"其他"需详细说明；
4. 点击【提交】；
5. 建议状态变为"已驳回"，同时反馈给智能体用于优化（人工接管统计口径之一）。

> 注意：驳回不会关闭原始异常事件。事件本身的处置请回到异常事件页继续。

### 5.5 查看审批历史

1. 在审批工作台点击【我已审批】或【全部】标签页；
2. 顶部筛选器支持按时间、建议类型、审批结果筛选；
3. 点击任一条记录查看完整审批档案：**审批人、审批时间、审批结论、审批理由、当时的建议原文**——所有信息不可篡改，供审计追溯；
4. 系统管理员可在"系统管理 > 审计日志"中查询全部审批记录（见 §8.3）。

## 6. 8D 报告

### 6.1 查看 8D 报告

1. 左侧导航点击【8D 报告】；
2. 列表显示已生成的报告，字段包括：报告编号、关联事件、创建人（智能体/人工）、状态（草稿/审核中/已发布）、更新时间；
3. 点击任一报告进入编辑页。

〔图 6-1：8D 报告编辑页截图 —— 左侧为 D1-D8 章节导航树，右侧为当前章节编辑区，顶部为保存/导出按钮〕

### 6.2 八个章节（D1~D8）说明

| 章节 | 名称 | 系统自动填充的内容 | 需要人工补充的内容 |
|---|---|---|---|
| D1 | 成立团队 | 建议的相关角色名单 | 实际指派的团队成员 |
| D2 | 问题描述 | 事件摘要、受影响批次、良率数据 | 现场照片（可选） |
| D3 | 临时围堵措施 | 审批通过的临时措施记录 | 执行确认 |
| D4 | 根本原因分析 | Top-3 嫌疑、证据链、确认的根因 | —（基本无需补充） |
| D5 | 纠正措施选定 | 已审批的调参/停线建议 | 措施理由补充 |
| D6 | 措施实施与验证 | 参数变更前后对比曲线、恢复数据 | 实施现场记录 |
| D7 | 预防再发生 | 知识图谱中提炼的关联风险点 | 制度/规范修订建议 |
| D8 | 团队祝贺 | — | 关闭与签署 |

### 6.3 编辑报告

1. 在左侧章节树中点击要编辑的章节（如 D5）；
2. 右侧编辑区中，白底可编辑文本框为可修改内容；灰底只读框为系统证据数据（不可修改，保证可追溯）；
3. 编辑后点击顶部【保存】（或使用 Ctrl+S 快捷键）；
4. 全部章节完成后点击【提交审核】，报告进入"审核中"状态，由质量工程师复核。

### 6.4 导出 PDF

1. 打开报告，点击右上角【导出 PDF】；
2. 在弹出的导出选项中勾选需要包含的附件（曲线图、图谱截图、案例附录）；
3. 点击【导出】，生成的 PDF 符合公司 8D 模板排版（页眉含公司标志与报告编号，页脚含页码与密级）；
4. 导出后报告状态自动更新为"已发布"（也可手动点击【发布】）。

> 系统自动生成的报告只是**初稿**，D1~D8 中标记"需人工补充"的部分务必由质量工程师确认后再对外发布。

## 7. 系统管理（系统管理员）

> 本章操作仅对"系统管理员"角色可见。其他角色看不到【系统管理】菜单。

### 7.1 用户管理

**路径**：系统管理 > 用户管理

| 操作 | 步骤 |
|---|---|
| 查询用户 | 在搜索框输入工号或姓名，点击【查询】 |
| 新增用户 | 点击【新增用户】→ 填写工号、姓名、部门、手机、邮箱 → 选择角色 → 点击【保存】（账号使用 Keycloak 统一认证，此处只做系统内信息登记与授权） |
| 编辑用户 | 点击行内【编辑】→ 修改信息 → 【保存】 |
| 停用/启用 | 点击行内【停用】（离职人员请及时停用，停用后立即无法登录） |
| 重置双因素 | 点击行内【重置 MFA】，用户下次登录重新绑定 |

〔图 7-1：用户管理页截图 —— 顶部搜索框与新增按钮，其下为用户表格〕

### 7.2 角色权限管理

**路径**：系统管理 > 角色权限

1. 左侧为角色列表（工艺工程师/设备工程师/生产主管/质量工程师/系统管理员）；
2. 点击角色，右侧显示该角色的权限矩阵：行=功能模块（看板/异常/根因/审批/8D/系统管理），列=操作（查看/操作/审批/导出/管理），勾选即开通；
3. 修改后点击【保存】，权限**立即生效**（在线用户下次点击菜单时刷新）；
4. 内置角色不可删除，可新建自定义角色。

> 变更权限前建议先在"审计日志"了解该用户的使用情况；权限变更本身也会记入审计日志。

### 7.3 审计日志查询

**路径**：系统管理 > 审计日志

1. 支持筛选：操作人、时间范围、操作类型（登录/查询/导出/审批/权限变更/数据修改）、结果（成功/失败）；
2. 常用场景举例：
   - "谁在昨晚导出了数据？" → 筛选操作类型=导出；
   - "误操作改了谁的权限？" → 筛选操作类型=权限变更；
3. 每条记录包含：时间、操作人、来源 IP、操作对象、动作、结果、详情；
4. 点击【导出】可将筛选结果导出为 Excel，供合规检查使用；
5. **审计日志保留 1 年**，任何人（包括管理员）不能修改或删除。

### 7.4 数据健康度

**路径**：系统管理 > 数据健康度

〔图 7-2：数据健康度页截图 —— 上半部为 6 个数据源状态灯卡片，下半部为 24 小时数据到达率曲线〕

| 显示项 | 含义 | 正常状态 |
|---|---|---|
| 数据源状态灯 | FDC / MES / 传感器时序 / 缺陷图 / Recipe / 工艺文档 6 个数据源的接入状态 | 绿灯 |
| 到达率曲线 | 每小时数据到达条数 vs 应到条数 | ≥ 95% |
| 缺失率 | 关键字段缺失占比 | < 2% |
| 延迟 | 数据从产生到入库的延迟 | < 2 分钟 |
| Kafka 积压 | 流处理队列积压条数 | < 1000 |

- 任何一项异常时卡片变黄（警告）或变红（中断），点击卡片查看明细与开始时间；
- 红灯超过 10 分钟会自动通知运维（详见《系统维护手册》）；
- 该页面是判断"系统数据可信度"的**第一入口**：怀疑数据不全时先看这里。

## 9. 常见问题 FAQ

| 编号 | 问题 | 解决办法 |
|---|---|---|
| Q1 | 登录时提示"账号或密码错误"，但密码确认没错 | 检查是否误开了大写锁定；确认用的是公司域账号密码（不是本系统单独密码）；仍不行联系 IT 服务台确认账号状态 |
| Q2 | 登录后页面空白，一直转圈 | 刷新页面（F5）；确认浏览器为 Chrome/Edge 110+；确认连接公司内网（在家需先连 VPN） |
| Q3 | 看板上没有数据或数据很旧 | 先看"系统管理 > 数据健康度"是否红灯（若非管理员请联系管理员）；再点击看板【刷新】按钮；仍无数据请报障并提供截图 |
| Q4 | 找不到某条告警 | 检查筛选条件（默认只显示近 24 小时）；尝试【重置】后按设备筛选；确认事件未被评为"误报" |
| Q5 | 审批工作台里找不到该我审批的建议 | 确认你是该建议类型的审批角色（调参→工艺工程师，停线→生产主管）；检查是否已在"我已审批"里处理过；检查建议是否超时升级给了上级 |
| Q6 | 点击【导出】后没有反应 | 检查浏览器是否拦截了弹窗/下载（地址栏右侧拦截图标选择"允许"）；导出大数据量需等待 10~30 秒；换个浏览器再试 |
| Q7 | 导出的 PDF 打不开或内容缺图 | 使用 Adobe Reader 或 Chrome 打开；勾选导出选项中的"包含附件"；文件较大时等待下载完成再打开 |
| Q8 | 根因分析一直没有结果（超过 10 分钟） | 可能数据不足或智能体服务繁忙，点击页面【重新分析】；仍失败请记录事件编号并报障 |
| Q9 | 实时推送收不到 | 检查页面右上角连接状态是否绿点；检查个人设置的通知渠道绑定；检查企业微信是否关注了企业应用 |
| Q10 | 知识图谱页面卡顿 | 图谱节点过多时会变卡，点击【收起下级】减少节点数；使用滚轮缩小视图后操作；推荐用 Chrome 打开 |
| Q11 | 误点了"标记误报"怎么办 | 打开事件详情，在处置时间线中点击【撤销误报标记】（24 小时内可撤销），并通知质量工程师 |
| Q12 | 置信度低的建议敢不敢直接通过 | 不建议。置信度 < 60% 表示证据不足，务必现场核实后再决策；也可以先驳回并填写"证据不足" |
| Q13 | 审批通过的调参建议如何撤销 | 在审批工作台"我已审批"中打开该建议，点击【申请撤销】并说明理由，需原审批链条上级确认 |
| Q14 | 8D 报告里灰色的内容为什么改不了 | 灰色内容是系统采集的证据数据，为保证可追溯不可编辑；如认为数据有误，请报障说明，由系统管理员核查数据源 |
| Q15 | 忘了密码导致被锁号 | 连续错 3 次会锁定 30 分钟；紧急情况联系 IT 服务台或系统管理员解锁 |
| Q16 | 换了电脑后界面布局变了 | 界面偏好保存在浏览器本地，新电脑需在"个人设置"重新配置显示偏好 |

## 10. 快捷键与使用技巧

### 10.1 快捷键

| 快捷键 | 作用 | 适用页面 |
|---|---|---|
| Ctrl + S | 保存当前编辑内容 | 8D 报告编辑页 |
| / | 聚焦搜索框 | 告警列表、审计日志 |
| R | 刷新当前页面数据 | 看板、告警列表 |
| Esc | 关闭当前弹窗 | 全局 |
| Enter | 确认弹窗提交 | 全局 |
| Ctrl + 点击 | 图谱多选节点 | 知识图谱 |
| 双击空白处 | 图谱缩放复位 | 知识图谱 |
| Tab / Shift+Tab | 在 Top-3 嫌疑卡片间切换 | 根因分析页 |

### 10.2 使用技巧

1. **每天上班第一件事**：打开看板扫一眼 4 张卡片——"待处理"有数字就先进异常列表清零；
2. **善用时间范围**：周会前切到"近 7 天"截图贴进周报，比手工统计快 30 分钟；
3. **看不懂建议时看案例**：审批前先看"相似历史案例"标签页，前人的处置与效果最有参考价值；
4. **勤反馈**：根因不对就点"都不对，反馈新根因"，反馈越多系统越准，你的团队是最终受益者；
5. **审批理由写清楚**：审计日志是永久记录，理由写清楚既保护自己也方便后人复盘；
6. **数据可疑先看健康度**：与其纠结数据对不对，不如先看数据健康度页的红绿灯。

## 11. 术语表

| 术语 | 释义 |
|---|---|
| 良率（Yield） | 合格晶圆（或芯片）数量占投入总量的比例 |
| OEE | 设备综合效率 = 时间开动率 × 性能开动率 × 合格品率 |
| FDC | Fault Detection & Classification，设备故障检测与分类系统，负责实时监测设备参数并产生告警 |
| MTTR | Mean Time To Recovery，平均恢复时间，从异常发生到恢复生产的平均耗时 |
| 根因（Root Cause） | 导致异常发生的最根本原因 |
| Top-3 嫌疑 | 系统分析后给出的可能性排名前三的根因候选 |
| 置信度 | 系统对某个结论的把握程度（0~100%），不等于正确率 |
| 知识图谱 | 用"点+线"表示设备、参数、工艺、缺陷之间关系的关系网络图 |
| 基线（Baseline） | 参数在正常状态下的历史波动范围 |
| Recipe | 设备执行的工艺配方（参数组合） |
| 批次（Lot/Batch） | 一同加工的一组晶圆，如 B-2026-1024 |
| 8D 报告 | 一种质量管理方法，通过 D1~D8 八个步骤完成问题解决与预防（Eight Disciplines） |
| HITL | Human In The Loop，人在环节中——关键决策必须由人确认 |
| 智能体（Agent） | 系统中自动完成特定任务的智能助手，如根因 Agent |
| 误报 | 系统报告了异常但实际并无异常的情况 |
| 人工接管率 | 智能体给出的建议中被人工推翻/改写的比例 |
| WebSocket | 一种让服务器主动把新消息推给页面的技术，"实时推送"靠它实现 |
| Keycloak | 公司统一登录认证平台，一个账号登录所有系统（SSO 单点登录） |
| 审计日志 | 记录谁在什么时间对什么做了什么操作的不可篡改台账 |
| 数据健康度 | 衡量各数据源接入是否完整、及时、可信的综合指标 |
| Kappa | 衡量两位标注人判断一致性的统计量，越接近 1 越一致 |
| P95 延迟 | 95% 的请求都比这个时间快，是衡量性能是否稳定的常用指标 |

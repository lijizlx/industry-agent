## 7. 源码交接说明

### 7.1 仓库结构

```text
ia/server              # Egg.js 4.0 业务后端
├─ app/                # controller/service/middleware（含审计中间件）

├─ src/pages/          # 看板/异常/根因/审批/8D/系统管理
├─ src/components/     # 图谱视图、曲线组件、审批卡片
├─ e2e/                # Playwright 用例
└─ Dockerfile

ia/agent               # FastAPI 智能体服务
├─ agents/             # monitor/root_cause/suggest/approval/report 五 Agent
├─ tools/              # 图谱查询/RAG检索/因果推断 MCP 工具封装
├─ eval/               # replay.py 50 样本回放评估
├─ demo/               # B-2026-1024 演练场景
└─ Dockerfile

ia/infra               # 基础设施与运维
├─ docker-compose.yml  # 单机演示/培训环境
├─ k8s/                # 生产/Staging manifests
├─ monitoring/         # Prometheus 告警规则、Grafana 看板 JSON
├─ backup/             # 备份/恢复脚本
├─ logrotate/
└─ training/           # reset_demo.sh 培训数据重置
```

### 7.2 本地启动步骤（开发/演示环境）

```bash
# 前置：Node.js 20+、Python 3.11+、Docker Desktop、pnpm

# 1) 启动基础设施（PG/Timescale/Kafka/Neo4j/MinIO/Keycloak）
cd infra && docker compose up -d
# 等待全部 healthy：docker compose ps

# 2) 执行数据库迁移与种子数据
cd ../server && npm i && npm run migrate && npm run seed

# 3) 启动业务后端（Egg.js，默认 7001，对外 /api/v1）
npm run dev

# 4) 启动智能体服务（FastAPI，默认 8000，对外 /agent）
cd ../agent && pip install -r requirements.txt && uvicorn main:app --reload

# 5) 启动前端（React 18，http://localhost:5173）
cd ../web && pnpm i && pnpm dev

# 6) 验证：浏览器打开 http://localhost:5173，用 seed 账号登录
```

### 7.3 迁移执行

- 数据库迁移：server 仓库 `npm run migrate`（可重入脚本，见维护手册 §7.4 双写过渡约定）；
- 图谱迁移：agent 仓库 `python tools/migrate_graph.py`（幂等，基于变更日志）；
- 首次部署按《部署方案》（IA-OP-001）执行；后续升级按维护手册 §7 升级流程。

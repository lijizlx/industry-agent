## 为用户生成两份 Python 3 学习类 PDF（桌面）

- 用户是前端开发，要启动一个 Python3 项目，不想系统学语法，需要「精简学习笔记」+「速查手册」两份 PDF，放在桌面同一个文件夹。
- 产出：`C:\Users\Admin\Desktop\Python3速成资料\` 
  - `Python3精简学习笔记.pdf`（44 页，11 章 + 2 附录，面向前端视角，含 JS→Python 对照表）
  - `Python3速查手册.pdf`（38 页，12 章，内置函数/标准库/正则/版本特性/陷阱表）
- 技术方案（可复用）：HTML + print CSS → Chrome 无头打印 → pypdf 补页码/书签。
  - 关键坑：桌面已开 Chrome 时 `chrome --headless=new --print-to-pdf` 会「交接」给已有实例而静默失败。
    解法：`--headless=old` + 每次唯一 `--user-data-dir`（tempfile.mkdtemp）。
  - 目录页码：标题里塞 1px 白色标记 `%%id%%`，第一遍导出后用 pypdf 提取文本定位页码，回填 TOC 再导出第二遍。
  - 中文页脚：reportlab 只画 `N / M`（Helvetica），避免 CID 字体问题。
- 排版经验：`pre { page-break-inside: avoid }` 会造成章末大片留白；改成 auto 又会出现只剩 3 行的孤页。
  最终保留 avoid，并靠内容微调（删 1~3 行 / 挪代码块位置）消除最差的 3 处孤页。
